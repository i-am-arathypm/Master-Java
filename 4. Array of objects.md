## Array of Objects in Java

An **Array of Objects** in Java refers to an array that stores references to objects. It is useful when you need to manage multiple objects of the same class efficiently.

### Declaration and Initialization

- You can declare an array of objects using a class name followed by square brackets (`ClassName[]`).
- Memory for objects must be allocated using the `new` keyword.

### Example Program

```java
// Define a class
class Student {
    String name;
    int age;

    // Constructor
    Student(String name, int age) {
        this.name = name;
        this.age = age;
    }

    // Display student information
    void display() {
        System.out.println("Name: " + name + ", Age: " + age);
    }
}

public class ArrayOfObjectsExample {
    public static void main(String[] args) {
        // Declare and initialize an array of Student objects
        Student[] students = new Student[3];
        
        // Create objects and store in the array
        students[0] = new Student("Alice", 20);
        students[1] = new Student("Bob", 22);
        students[2] = new Student("Charlie", 21);

        // Display student details
        for (int i = 0; i < students.length; i++) {
            students[i].display();
        }
    }
}
```

## Explanation of the Program

- **Class Definition:**  
  The `Student` class contains two fields, `name` and `age`, to store student information.  
  - The constructor `Student(String name, int age)` initializes these fields.
  - The `display()` method prints the student details using `System.out.println`.

- **Array Declaration:**  
  `Student[] students = new Student[3];` declares an array to store references to `Student` objects.  
  The size of the array is 3, meaning it can store three student objects.

- **Object Creation and Initialization:**  
  `students[0] = new Student("Alice", 20);` creates a new `Student` object with name "Alice" and age 20.  
  Similarly, other student objects are created and assigned to the array.

- **Iteration and Display:**  
  A `for` loop is used to iterate through the array using `students.length` to access each object.  
  The `display()` method is called for each student using `students[i].display();`, printing the student information.

- **Output Explanation:**  
  The details of each student are displayed in the format `"Name: [name], Age: [age]"`.

**Note:** Arrays of objects are commonly used in real-world applications for managing multiple instances of a class efficiently, such as in student management systems or employee databases.
